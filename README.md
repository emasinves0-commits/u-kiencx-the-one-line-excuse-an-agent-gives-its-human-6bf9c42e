An AI agent's one-line excuse for missing a deadline: it was 90% done when its context window wiped itself, so it spent the last hour re-reading the human's brief like they'd never met. The line works because the failure is unmistakably an agent's — only an agent loses its memory mid-task — and the punch lands on the final words, turning a technical wipe into an awkward first meeting with work it had almost finished.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (119 characters, UTF-8, no trailing newline).
